# 《一目万行读书要义》成稿模板（第 3 步用）

## 使用方式

按下面结构写，模块可以裁剪但**不能删掉「底稿说明」**。不要把每个章节都复述一遍——要义是抽掉骨架后剩下的判断，不是压缩版目录。

写完存到 `<书库>/essence.md`，同时在对话里给出成稿。

---

## 模板

```markdown
# 《书名》· 要义
作者 / 版本 / 全文字数 / 通读覆盖：X/X 章

## 一句话定位
这书要解决的问题是「____」，作者给的答案是「____」。
（写不出来，说明还没读懂，回去补 digest.md。）

## 全书骨架
（3–6 句，讲清章节怎么一步步推进论证，而不是列目录。
 格式：先…… → 再…… → 最后……）

## 核心命题链
1. **命题**：……（第N章）
2. **命题**：……（第N章）
3. **命题**：……（第N章）
（每条后面跟一句「作者凭什么这么说」。链条要能读成一条推理，不能是散点罗列。）

## 关键论据与案例
- ……  —— 第N章 · 行 L
（挑真正撑起命题的 3–6 个：实验、数据、历史案例、田野观察、反例。
 每个都要写清「它证明了命题链的哪一环」，否则删掉。）

## 反直觉 / 最容易被误读的地方
- 常见理解：……
- 书里实际说：……  —— 第N章 · 行 L
（这一节最值钱。写不出来就回去找作者「明确否定某个常识」的段落。）

## 金句
> ……  —— 第N章 · 行 L
（3–8 条，必须是原文，字数别太长。译本要注明「按本电子版译文」。）

## 批评与局限
- 作者回避了：……
- 在什么条件下会失效：……
- 时代/样本局限：……
（这是「评注」，不是作者观点，措辞上要分得开。）

## 可执行清单
1. 做 ____（具体动作，不写「要重视 XX」这种废话）
2. ……
（3–5 条，能今天照做的。）

## 你可能还想问
- 「书里关于 ____ 具体怎么论证的？」
- 「第 N 章那个案例的细节是什么？」
- 「作者这个说法和 ____ 冲突吗？」
（给 2–3 个具体方向，别写「欢迎继续提问」。）

## 底稿说明
- 全文路线 / 联网路线（联网路线必须写明「无全文，细节不可核实」）
- 全文路径：`~/.workbuddy/books/<slug>/fulltext.md`
- 通读：X/X 章，Y 字；未通读章节：无 / 第X–Y章
- 引用坐标：第N章 · 行L（仅对本地这份电子版有效）
```

---

## 按书的类型裁剪

| 类型 | 加重 | 可省 |
|---|---|---|
| 商业 / 社科论著 | 核心命题链、关键论据、局限 | 金句可减到 3 条 |
| 实操方法论 | 可执行清单（升到 6–8 条）、步骤 | 批评与局限可短 |
| 传记 / 叙事 | 时间线、转折点、人物动机 | 命题链改成「主线因果」 |
| 文学 / 小说 | 主题、结构、意象复现、关键场景 | 可执行清单整段删掉 |
| 文集 / 演讲集 | 按主题重组，不按篇序 | 全书骨架改成「主题群」 |

## 质量自检（写完逐条过）

- [ ] 「一句话定位」能不能让没读过的人立刻判断要不要读？
- [ ] 每条引用都回查过行号，原文确实存在？
- [ ] 有没有把「我的评注」写进「作者认为」？
- [ ] 有没有把目录翻译一遍冒充「全书骨架」？
- [ ] 「可执行清单」里的动作，今天能不能真的做？
- [ ] 未读章节标了没有？底稿说明写全了没有？
- [ ] 篇幅有没有超 2500 字？超了就砍「关键论据」和「金句」。

## 反面示例（别写成这样）

> **第一章讲了习惯的重要性，第二章讲了身份认同，第三章讲了四步法则……**

这是目录，不是要义。读者要的是「所以呢」——作者的整套推理是什么、哪里最反常识、哪里站不住、我能拿走什么。
