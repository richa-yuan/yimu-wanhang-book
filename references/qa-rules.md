# 追问应答纪律（第 4 步用）

目标：用户问的是**这本书里的事**，不是你的通识。回答必须可回溯、可证伪。

---

## 一、标准动作

```
1. 拆问题：用户到底要「原话」「论证」「位置」还是「评价」？
2. 抽关键词：2–4 个，优先书名里的特有概念、人名、案例名、作者自造词
3. 检索：lookup.py <书> 词1 词2 [-C 3]
4. 命中 → Read 命中处上下文 / 整章（--chapter N --max 0），确认语境
5. 未命中 → 换同义词、拆短词、去掉修饰，最多再试 2 轮
6. 仍无 → 明确说「书里没找到」
7. 作答：结论 → 原文依据 → 展开
```

关键词技巧：

- 中文别搜整句，搜 2–4 字核心词（「身份认同」优于「作者认为身份认同决定行为」）。
- 译本用词可能不同，同时试几种译法：「复利 / 复合效应 / 累积效应」。
- 英文书用英文词搜；`--regex` 支持正则，别滥用。
- 涉及「作者怎么论证 X」这种跨章问题，先搜出 X 的所有出现位置，再读每一处前后各 20 行。

---

## 二、引用格式（统一，不许变体）

```
> 「原文原句」 —— 《书名》第N章 · 行 L
```

- 行号来自 `fulltext.md`，只对本地这份电子版有效。
- 引文必须逐字抄，不改写、不拼接、不省略后加省略号冒充原文。
- 一句话不够说明语境时，可以引 2 句；最多 2 句，其余转述。
- 写完引用**回查一次行号**。这是硬要求，编造引用是本技能最严重的失败。
- 章节标题被切成「区块 N」的书，写「区块 N · 行 L」，并说明「本电子版未识别出规范章节」。

---

## 三、答案结构

```
【结论】1–3 句，先回答问题，别铺垫。
【依据】> 原文引用 + 坐标
【展开】为什么这个说法成立 / 在你问的语境里意味着什么 / 和书里别处的关联
```

需要分情况时，用「书里其实给了三种情形」开头，别写「这要看情况」然后绕。

---

## 四、四种难缠情况

### 1. 书里没写

直接说，别圆场。给出三种区分：

- **「全书没检索到，作者应该没谈这个」**——换过 2 轮关键词仍无命中。
- **「书里提到了，但只是一笔带过」**——引用那一处，说明没有展开。
- **「这个问题超出了本书范围」**——书里连相关概念都没有。

禁止：用模型自身知识补一段，再含糊地说「书里大概也是这个意思」。

### 2. 作者前后不一致

这是高价值发现，照实摆出来：

> 第 3 章 · 行 412 说「A」；第 9 章 · 行 2380 却说「非 A」。作者没有交代这两处怎么调和。

不要替作者找补，不要选一个你更认同的当标准答案。可以在「我的评注」里给可能解释，但必须标注是推测。

### 3. 用户想要书外信息

可以给，但必须隔开：

```
【书里怎么说】……（带引用）
【书外补充】以上是我另外补的背景，不在本书中：……
```

用户问「这个说法现在还成立吗」这类问题，几乎必然要书外补充——先给书里的，再明确标书外的。

### 4. 用户要评价、要立场

可以评价，但把事实层和判断层分开：

- 事实层：作者说了什么（引用）。
- 判断层：「我的判断是……」——这是你的观点，不是作者观点。

不要写「作者其实想表达……」然后塞进自己的解读。

---

## 五、跨轮追问

- 每次回答前先 `lookup.py --list` 或直接用已确认的 slug，别每轮都重新猜书名。
- 用户提到「刚才那个概念」：从上文找具体词，别自己脑补。
- 用户连续追问同一章：直接 `--chapter N --max 0` 拉全章读，比反复检索准。
- 回答里用到的新原文，顺手回填 `quotes.md` / `glossary.md`，书库越用越厚。

---

## 六、联网路线（无全文）时的追问

开头重复一次声明：**本次没有电子书全文，细节无法核实。**

- 能给：公认要点、章节主题、外界评价、观点争议。
- 不能给：逐字引文、具体行号/页码、某章某个案例的细节。
- 用户追问细节 → 说「无全文无法核实，最接近的公开材料是……」，并主动提议补建档。
- 用户补了电子书 → 立刻走第 1 步建档，之后所有回答切回全文路线。

---

## 七、自检清单

- [ ] 结论放在第一段了吗？
- [ ] 引用回查过行号吗？原文逐字吗？
- [ ] 「作者认为」和「我的评注」分开了吗？
- [ ] 书外信息显式标注了吗？
- [ ] 没找到时是说「没找到」，而不是编一段吗？
- [ ] 用户问的是 A，答的是 A 吗？
